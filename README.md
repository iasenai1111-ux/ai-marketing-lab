# AI Marketing Lab

Laboratório de experimentos curtos com IA, dados e automação aplicados a marketing. Cada experimento parte de uma pergunta, registra como foi testado e mostra o resultado, inclusive o que não funcionou.

## Experimentos

| Nº | Pergunta | Resultado | Tecnologias |
|---|---|---|---|
| [01](experimentos/01-classificador-de-comentarios) | Até onde chega um classificador de comentários feito só com palavras-chave? | 74,3% de acurácia; falha em negação e contraste | Python · pandas |
| 02 | Um LLM classifica os mesmos comentários melhor? A que custo? | 🔜 em breve | Python · LLM |

## Como contribuir (alunos)

1. Faça um *fork* deste repositório.
2. Copie [`experimentos/MODELO.md`](experimentos/MODELO.md) para uma pasta nova com o seu experimento.
3. Responda uma pergunta sua: outro dataset, outro modelo, outra métrica.
4. Publique no seu GitHub. Se quiser, abra um *pull request* para aparecer aqui.
